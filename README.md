# AI Chat Assistant — standalone demo

A focused, responsive conversational assistant interface built with plain HTML, CSS, and browser JavaScript. The app presents a conversation thread, prompt suggestions, and a message composer. Sending a message adds it to the thread and returns an illustrative response selected locally from a few sample templates.

## Implemented interactions

- Type a message and select **Send**, or press **Enter** to send; **Shift + Enter** inserts a new line.
- Click any prompt suggestion to place its sample prompt into the composer for review or editing.
- Receive a short local illustrative reply after sending; the sample is selected using simple browser-side keyword matching.
- Start a fresh conversation using the reset control or **Ctrl/Cmd + K**.
- Use the help control to read a short explanation of the demo boundary.
- Resize the page for a responsive desktop or mobile layout, with keyboard focus indicators and accessible message announcements.

## Sample and integration boundary

All replies are synthetic examples generated by local JavaScript templates and simple keyword matching. They are demonstration-only, may be generic or inaccurate, and are not advice. The app makes no live AI/API request and does not connect to a model, backend, account, or network service. Messages exist only in the current browser page and are not persisted.

The technology names **Next.js, Python, FastAPI, and OpenAI** are reference stack only; they describe a potential full-stack version, but none is connected or used by this no-build browser demo. The delivered project runs as static files and uses no framework, package manager, server-side code, credentials, external scripts, assets, fonts, or network requests.

## Launch

Open a terminal in this folder and run:

```sh
python3 -m http.server 8765
```

Then open <http://localhost:8765> in your browser.
